# Repository Tugas Pengolahan Citra

Selamat datang di repository tugas mata kuliah **Pengolahan Citra**. Repository ini berisi kumpulan latihan praktikum (jobsheet) dan tugas yang dikerjakan menggunakan Python.

## 📌 Deskripsi Proyek

Proyek ini dibuat untuk mendokumentasikan hasil pengerjaan tugas-tugas pengolahan citra, mulai dari pemahaman dasar berkas gambar hingga teknik manipulasi citra yang lebih kompleks. Fokus utama dari tugas ini adalah pemahaman konsep teori yang diimplementasikan langsung ke dalam kode program.

---

## 🛠️ Prasyarat (Prerequisites)

Untuk menjalankan program di repository ini, Anda bisa menggunakan salah satu dari metode berikut:

- **Google Colab**
- **Lokal**: [Python 3.x](https://www.python.org/) & [Jupyter Notebook](http://jupyter.org/install)

Daftar pustaka (libraries) yang digunakan:

- **NumPy**: Untuk manipulasi array dan data numerik citra.
- **Matplotlib**: Untuk visualisasi dan menampilkan gambar.
- **OpenCV (cv2)**: Untuk pemrosesan citra digital.

Jika menggunakan Colab, library ini sudah tersedia secara default. Untuk lokal, Anda dapat menginstalnya dengan:

```bash
pip install numpy matplotlib opencv-python
```

## 🚀 Cara Menjalankan

### ☁️ Google Colab

1. Buka [Google Colab](https://colab.research.google.com/).
2. Pilih tab **GitHub**.
3. Masukkan URL repository ini: `https://github.com/hanifaslam/pengolahan-citra`.
4. Pilih file `.ipynb` yang ingin dijalankan (misal: `jobsheet_01/jobsheet_01_pengolahan_citra.ipynb`).

### 💻 Lokal

1. Clone repository ini ke komputer lokal Anda:
   ```bash
   git clone https://github.com/hanifaslam/pengolahan-citra.git
   ```
2. Masuk ke direktori proyek (`cd pengolahan-citra`).
3. Jalankan Jupyter Notebook (`jupyter notebook`).
4. Buka folder `jobsheet_XX` dan pilih file `.ipynb`.
